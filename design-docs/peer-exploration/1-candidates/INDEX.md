# Stage 1 master index

181 unique projects, deduped from 191 blocks across nine territory surveys. Built 2026-09-10.

Every star count, commit count and last-push date was read from the GitHub API rather than from a page or from memory; commit counts come from the `rel="last"` page number of a one-per-page commits request. Anything that could not be verified is marked `unverified` rather than estimated.

Each row's full entry, including its description, lives in the territory file named in the section heading. Within a section, projects keep their surveyor's ordering: most interesting mechanism first, not most popular.
