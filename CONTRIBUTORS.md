# Contributing to CCCandybar

Thanks for your interest in contributing.

## Getting started

1. Fork the repo and clone your fork.
2. Install dependencies: `pnpm install`
3. Build: `pnpm run build`
4. Run tests: `pnpm test`

## Submitting changes

- Create a branch off `main` for your work.
- Keep changes focused — one concern per PR.
- Run `pnpm run lint` and `pnpm run typecheck` before opening a PR.
- Open a pull request against `main` with a clear description of what changed and why.

## Reporting issues

File bugs and feature requests at https://github.com/promptctl/cc-candybar/issues.
